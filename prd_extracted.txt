1. Executive Summary
This document defines the complete product requirements for the "Subtraction within 100 Using the Relationship Between Addition and Subtraction" interactive lesson module. The module is part of Intellia SG's Grade 2 Math program and targets Singapore Primary 2 students aged 7–8.

The module teaches students that addition and subtraction are inverse operations — that knowing one addition fact unlocks two related subtraction facts. This is a cornerstone concept in the Singapore MOE Primary 2 Mathematics syllabus, building critical mental computation strategies and algebraic thinking foundations.

The product is a standalone web page hosted at:
https://intelliasg.com/courses/grade-2-math/
It is built using React 18 (Vite + JSX) and strictly mirrors the visual and UX structure of https://numberbound.vercel.app/ and the repository https://github.com/dsamyak/numberbound. Audio narration uses the ElevenLabs pipeline (Voice: Alice, ID: Xb7hH8MSUJpSbSDYk0k2) as established for all Intellia SG modules.

The module follows Intellia's 5-Phase Learner Journey:
Phase 1 — WONDER: Curiosity hook — "Can a secret code unlock subtraction?"
Phase 2 — STORY: Narrative-based concept introduction with English characters & image placeholders
Phase 3 — SIMULATE: Sandbox-style interactive simulation (3 stations — CPA progression)
Phase 4 — PLAY: IntelliPlay™ — 100 randomised gamified practice questions
Phase 5 — REFLECT: Journal / LearnFlow AI prompt — consolidate understanding

5.1 Phase 1 — WONDER (~1–2 minutes)
Hook: "If 48 + 35 = 83... then what is 83 − 48? Can one fact unlock two secrets? 🔍"

Animated sequence: a number equation appears on screen, pieces slide apart
Mascot (LearnFlow) poses the mystery question with a curious expression
Brief animation shows how 3 number facts live inside one "fact family triangle"
Child taps to reveal the connection — the hook resolves partially, sparking desire to learn more
Audio: ElevenLabs Alice narrates the hook in "thinking" style (gentle, inviting, curious)
Ends with: "Let's go on a quest and discover the secret of subtraction!"

5.2 Phase 2 — STORY (~2–3 minutes)
Characters: Lily & Max (English names) | Image placeholders for custom illustrated panels

The story introduces the concept through a relatable narrative with English characters. All story panel images are empty placeholders for custom-generated illustrations to be added later.

Story Narrative: "The Magic Sandwich Shop"

"Lily and Max run a sandwich shop. One morning, they baked 63 sandwiches."
Panel 2 — [IMAGE PLACEHOLDER: Lily counting sandwiches on a shelf]:

Each panel is narrated by ElevenLabs Alice in "statement" style. The number bond diagram updates visually on Panel 5. The story explicitly models the key learning objective: deriving a subtraction fact from an addition fact.

5.3 Phase 3 — SIMULATE (~5–6 minutes)
Three progressive simulation stations mirror the CPA (Concrete → Pictorial → Abstract) approach of the Singapore mathematics curriculum. Each station must be completed before the next unlocks.

Station A — Base-10 Block Take-Away (Concrete)
Visual: Animated tens blocks and ones blocks representing a 2-digit number
Interaction: Child drags blocks from the "total" area to a "taken away" basket
Number bond diagram updates in real-time as blocks are removed
Displayed equation: "[whole] − [part1] = [part2]" updates dynamically
Teaching moment: "You just found the missing part! You did subtraction!"
Range: Numbers within 50 for this station (foundation)

Station B — Fact Family Triangle Builder (Pictorial)
Visual: An animated fact family triangle with three circles connected by lines
One number is missing — shown as a dashed circle with "?" inside
Child drags the correct number tile from a selection of 4 options into the circle
On correct: the triangle animates a "lock-click" effect, then shows all 4 related facts
e.g., whole=82, part1=47, part2=35 → shows 47+35=82, 35+47=82, 82−47=35, 82−35=47
5 problems; advances after 4/5 correct
Range: Numbers within 80 for this station (core range)

Station C — Number Sentence Inverter (Abstract)
Visual: An addition sentence is shown: "47 + 35 = 82"
Below it: An incomplete subtraction sentence with one blank: "82 − 47 = ___"
Child types or taps the answer using a large, touch-friendly number pad
Hint button: "Show me the fact family triangle" → triangle animates into view
Teaching point: "The subtraction sentence is hiding inside the addition sentence!"
5 problems; mix of finding part1, part2, and whole
Range: Numbers within 100 for this station (full range)

7.3 Feedback Mechanics
✅ Correct Answer: Bounce animation + ElevenLabs celebration audio + "Brilliant! You found the inverse! 🎉"
❌ Incorrect Answer: Gentle shake animation + "Let's try again! Use the fact family triangle 🔼"
Hint 1: Fact family triangle highlights the known values with arrows
Hint 2: Base-10 blocks animate to show the subtraction concretely
After 2 Failed Attempts: Answer revealed with animated step-by-step explanation
No negative scoring — encouragement-first. Incorrect answers never reduce XP.

10. Content Specifications
10.1 Simulation Visuals
Fact family triangles: SVG-rendered, animated fill, 3-circle connected structure
Base-10 blocks: Animated tens rods and ones cubes (Concrete station)
Bar models: Horizontal rectangular part-whole representation (Pictorial station)
Number sentences: Large, clear typography with animated blank fill

10.2 Question Bank Rules
All 100 questions unique — no duplicates
Randomised per session using Fisher-Yates shuffle algorithm
No two sessions present the same question order
MCQ distractors: plausible, within ±5 of correct answer, include common error patterns
Word problems strictly follow Singapore MOE "Let's Think Along" format
English character names only — Lily, Max, Emma, Oliver, Sophie, Jack, Mia, Ben, Charlotte, Noah

10.3 Story Panel Specifications
6 narrative panels total (see §5.2)
Each panel: [IMAGE PLACEHOLDER] + narration text + dialogue text
Image placeholders: 560 × 320px (16:9 ratio), dashed border, label with scene description
Illustrator brief included in placeholder label (e.g., "[Image: Lily and Max in a colourful sandwich shop]")
Final illustrations to be generated separately and dropped into placeholder containers
